# UIデザイン仕様

`src/styles.css`に定義された実際のデザイントークン・スタイルパターンを転記する。Tailwind等のCSSフレームワークは使わず、CSSカスタムプロパティ＋素のCSSで実装している（D-001）。

## デザイントークン（`:root`）

| 種別 | 変数 | 値 | 用途 |
|------|------|-----|------|
| 色 | `--bg` | `#ffffff` | 背景（基本） |
| 色 | `--bg-muted` | `#f5f5f3` | サムネイル背景・プレビュー背景等の淡いグレー |
| 色 | `--fg` | `#222222` | 本文文字色 |
| 色 | `--muted` | `#757575` | 補助テキスト（日時・ラベル等） |
| 色 | `--border` | `#e2e2e0` | 枠線 |
| 色 | `--accent` | `#4a6b8a` | アクセント（FAB・選択状態・アクティブタブ） |
| 色 | `--danger` | `#b3453f` | 削除等の破壊的操作 |
| 余白 | `--sp-1`〜`--sp-6` | `4px, 8px, 16px, 24px, 32px, 48px` | 8段階の余白スケール |
| 角丸 | `--radius` / `--radius-lg` | `12px` / `20px` | ボタン・カード / ボトムシート |
| フォント | `--font-sans` | `'Noto Sans JP', -apple-system, BlinkMacSystemFont, sans-serif` | 全体のフォント |

警告バッジ・Undoバー（`.editor__warning-badge`／`.editor__undo-bar`）は上記トークン外の色（背景`#fff4e0`・文字`#8a5a00`・枠`#f0d9a8`）を使用しており、注意喚起系の共通配色として2箇所で再利用している。

## フォント

- `@fontsource/noto-sans-jp`の400/500/700ウェイトをCDNなしでバンドルし、CSSの`@import`で読み込む（オフライン動作のため）。
- スライド内の見出しは700(bold)、本文は400、強調時は700。

## コンポーネント別スタイル方針

- **スライドレンダリング（`.slide-view*`）**: 1280×720の仮想座標を`transform: scale()`で実表示サイズへ縮小する絶対配置レイアウト。ライブプレビュー・フィルムストリップ・レイアウト候補カルーセル・発表画面すべてで同じコンポーネント（`SlideView`）を幅だけ変えて再利用する。
- **カード/リスト（Home）**: `.deck-card`は角丸20px・1pxボーダーの白背景カード。サムネイルは96×54（16:9）。
- **FAB**: 右下固定、56×56の円形、`--accent`背景、影付き。
- **ボトムシート（`.sheet` / `.sheet-backdrop`）**: 画面下からせり上がる角丸シート。長押しメニュー・警告詳細・レイアウト候補選択で共通利用。
- **エディタツールバー（`.editor__tool`）**: 横スクロール可能なピル型ボタン列。アクティブ状態は`--accent`背景＋白文字（`.editor__tool--active`）。
- **発表画面（`.present*`）**: 黒背景＋中央の白い16:9ステージ。オーバーレイは半透明の文字影付きテキストで、`pointer-events: none`のコンテナに`pointer-events: auto`の子要素（終了ボタン等）のみ操作可能にする構成。

## アクセシビリティ・その他

- `prefers-reduced-motion: reduce`時はアニメーション/トランジションをほぼ無効化する共通ルールを`:root`直下に定義。
- 画像ブロックには`alt`をユーザーが編集できるUI（Editor画面の「画像の説明」ボタン）を用意し、`SlideView`のレンダリングにも反映する。
- タップ操作中心のUI（ボタン最小サイズ・長押し/スワイプジェスチャー）を前提とし、`-webkit-tap-highlight-color: transparent`でネイティブアプリに近い触感にしている。

# 要件定義

「どこでもプレゼン」は、テキストを入力するだけで自動的にスライドレイアウトが決まる、Android向けの軽量プレゼン作成・発表アプリである。

## 要求された要件（要約）

- 発表資料をゼロから作れる、シンプルなプレゼン作成・発表アプリをAndroidアプリ（APK）として提供する。
- テキストを入力するとレイアウト（見出し・箇条書き・2カラム・画像＋文章など）を自動で組み立てる「自動レイアウトエンジン」を中核機能とする。
- 作ったスライドはPNG画像・PDFとして書き出せること。
- AIによる補助（長文の要約、読みやすさの評価、レイアウト候補の提示）を備えること。
- オフラインで完結すること（外部LLM API等のネットワーク依存を持たない）。
- 開発中はWeb/PWAとして進めてよいが、最終的にはCapacitorでAndroid化しAPKとして納品する。
- 実装・テスト・各種ドキュメント（要件定義・画面遷移・デザイン仕様・アーキテクチャ・データ構造・ビルド手順・運用ガイド等）一式を納品物とする。

## 実装で確定した仕様

### 画面構成（3画面）
- **Home画面**: デッキ（プレゼン資料）の一覧、新規作成、複製・JSON書き出し/読み込み・PDF書き出し・削除。
- **Editor画面**: テキスト入力とライブプレビュー、マーカー/強調、画像追加、レイアウト候補選択、PNG書き出し、発表メモ、スライド並べ替え・追加・削除。
- **Present画面**: 16:9固定でのフルスクリーン発表表示。左右スワイプでページ送り、ダブルタップでUI表示切替、画面回転ロック、経過時間表示。

詳細な画面構成・遷移は [screens.md](./screens.md) を参照。

### 自動レイアウトエンジン
- 入力テキストを行の記号（`・` `-` `*`）・空行から見出し/箇条書き/段落へパースする。
- キーワード辞書（結論・理由・結果・課題・まとめ・提案・リスク・ポイント等）・文の長さ・数値単位の有無から重要度と自動強調を判定する。
- ブロック構成（画像有無・箇条書き数・ブロック数）から5種類のテンプレート（title/statement/bullets/twoColumn/imageSide）のいずれかを自動選択する。`layoutHint`で手動固定も可能。
- 1280×720の仮想座標系にフォントサイズ・行送りを二分探索で決定し、収まらない場合は警告（`too-much-text`等）を出す。
- レイアウト判断ロジックはレンダラ非依存の純粋関数（`layoutSlide`）に一元化し、DOMプレビュー・Canvas描画・PNG/PDF出力すべてが同じ結果を共有する（D-002）。

### AI補助（すべてルールベース・オフライン、外部API不使用）
- **要約**: キーワード一致・文の位置・数値単位・長さでスコアリングした抽出型要約（生成的な作文はしない）。
- **読みやすさ評価**: 1行文字数・行数・漢字比率・句読点密度から0〜100のスコアと改善ヒントを算出。
- **レイアウト候補提示**: 6種類（自動+5テンプレート）を実際の`layoutSlide`結果でプレビューするカルーセルUI。

### データ永続化
- IndexedDBにデッキ本体（メタデータ＋テキスト）とアセット本体（base64画像）を分離して保存し、800msデバウンスで自動保存する。
- JSONエクスポート/インポートに対応し、インポート時はスキーマ・型を検証してから取り込む。

### 出力
- PNG書き出し（スライド1枚単位、オフスクリーンCanvas）。
- PDF書き出し（デッキ全体、`pdf-lib`でPNGを1ページ1枚として結合）。

### Android化
- Capacitor 8で`android/`ネイティブプロジェクトを生成し、debug APKのビルドに対応する（手順は[build-android.md](./build-android.md)参照）。
- `@capacitor/screen-orientation`（発表画面の横向き固定）・`@capacitor/share`・`@capacitor/filesystem`（PNG/PDFの保存・共有）をネイティブ実行時のみ使用し、Web版では既存のブラウザAPIにフォールバックする。
- ファイル選択（画像追加・JSON読み込み）は既存のWeb `input[type=file]`のままとし、カメラ機能（`@capacitor/camera`）は要件上不要のため追加していない。
